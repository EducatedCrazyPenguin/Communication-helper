# Privacy

Default processing stays local. No analytics/CDN/fonts/cloud STT. Coach receives transcript text only; explicit remote HTTPS configuration and session consent are required before it leaves the device. Windows Credential Manager stores provider secrets; there is no plaintext fallback. Isolated test roots do not access everyday settings/vault entries.

Local storage is not encryption against another process using your Windows account. Session deletion removes owned evidence and aggregate contributions. Audio-only deletion keeps text/metrics only when deliberately selected. Delete All clears Gym-owned data/settings/logs/backups and credentials, not shared model caches or other applications. Locked files remain pending deletion, not falsely reported removed. External exports/backups cannot be recalled; SSD secure erasure is not claimed. Ordinary logs contain IDs, timings and safe error codes, not transcripts.

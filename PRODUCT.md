# Communication Gym
<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Approved execution plan: Python/FastAPI, local HTML/CSS/ES modules, SQLite. No frontend build or CDN.

## Users
One personal user practicing spontaneous technical and everyday communication on Windows, in English, Hindi and natural Hinglish.

## Product Purpose
Train independent transfer of thought structure to another listener. Success means naming, defining, relating, differentiating, explaining consequences and concluding—not simply receiving a rewritten speech.

## Operating Context
Local topic and preparation, recorded first attempt, original STT, evidence-backed top-three feedback, independent listener reconstruction, verbal questions, shorter same-topic retry, comparison, rolling progress.

## Capabilities and Constraints
Original sibling STT package is preferred. Immutable audio/ASR and separate corrections. Provider-independent reasoning. Optional external VoiceStudio. No automatic cloud upload, large download, voice clone, analytics or emotion/medical inference. Actual runtime verification is distinct from synthetic fixtures.

## Brand Commitments
Approved quiet task-focused notebook surface; simple personal tool, no enterprise dashboard. Natural language, no corporate rewrites.

## Accessibility & Inclusion
English/Hindi/Hinglish text, Devanagari support, semantic labels, keyboard focus, responsive desktop/narrow browser layout. Accent, code switching and thinking pauses are not communication failures by themselves.
